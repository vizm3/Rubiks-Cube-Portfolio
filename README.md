# 🧩 Anand Mahadev | Developer Portfolio

Personal portfolio of **Penumudi Anand Mahadev**, a final-year AI & Machine Learning student who builds full-stack apps, RAG systems and cloud-deployed ML projects.

The site is built around an interactive 3D Rubik's Cube, with smooth animations and a responsive single-page layout.

🔗 **Live site:** `https://vizm3.github.io/Rubiks-Cube-Portfolio/`

---

## ✨ Features

- Interactive **3D Rubik's Cube** built from 27 cubies using CSS 3D transforms
- Drag-to-rotate with inertia, plus **Scramble** and **Solve** buttons
- Typewriter role text and animated stat counters
- Flip-style skill cards with 3D spinning cubes
- Project cards with tech stack, highlights and links
- **Holographic certification cards** with tilt, glare, and a badge ⇄ certificate flip
- Custom cursor, scroll progress bar and floating canvas particles
- Contact form that opens the visitor's mail app with the message pre-filled
- Fully responsive, including a mobile navigation menu

---

## 🛠 Tech Stack

- **HTML5**, **CSS3**, **vanilla JavaScript** (no frameworks or build step)
- CSS 3D transforms for the cube
- Canvas API for background particles
- Google Fonts: Space Grotesk and JetBrains Mono
